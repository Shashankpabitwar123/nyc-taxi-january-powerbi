# Portfolio-Ready Summary

## Short description

Built a three-page Power BI data-quality and operations report for January 2025
NYC Yellow Taxi trip data. Loaded Parquet and taxi-zone lookup data from Azure
Blob Storage, created a star-schema model with date/zone/payment/rate
dimensions, wrote DAX measures for valid and excluded populations, reconciled
3,475,204 raw rows, and documented the model and assumptions.

## Resume-style bullets

- Built a Power BI star-schema model for 3.48M NYC Yellow Taxi January 2025
  trip rows using Power Query, Azure Blob Storage, DAX, and reusable date,
  zone, payment-type, and rate-code dimensions.
- Designed a three-page report covering executive KPIs, hourly/date trends,
  top pickup/drop-off zones, payment/rate-code mix, and data-quality
  methodology.
- Implemented validity-aware measures and reconciled 3,251,098 valid trips
  plus 224,106 excluded trips back to the 3,475,204-row raw population
  (93.55% validity rate).

## Honest scope statement

The delivered analysis is for January 2025. Extending the model to all 2025
months is a planned future phase and is not represented as completed work.
